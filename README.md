# Bytari FileSweep

Bytari FileSweep is an automated file cleanup and organization tool designed to keep folders tidy, structured, and consistent. It renames files, sorts them into categorized folders, detects duplicates, and generates a cleanup report — all with simple, configurable rules.

## Features
- Auto‑rename files based on patterns (prefixes, dates, categories)
- Sort files into folders by type (PDF, images, docs, audio, zips)
- Detect duplicates using file hashing
- Generate a cleanup report (JSON or text)
- Optional junk cleanup for temp or partial files
